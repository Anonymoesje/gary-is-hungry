# Gary Is Hungry

A one-button chase game in a single HTML file. Flip gravity, keep running, and don't let Gary eat you.

- Daily course that is the same for everyone
- Challenge links that let friends race your ghost
- Party mode for 2 to 4 players on one screen

Play it at https://anonymoesje.github.io/gary-is-hungry/

`index.html` is the source. Run `node build.js` to rebuild `docs/index.html`, which GitHub Pages serves.
